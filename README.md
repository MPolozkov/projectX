# **API для Библиотеки**

## *Описание проекта:*

RESTful API для базового управления библиотечным каталогом. 
Система позволят управлять информацией о книгах и читателях, а также процессом выдачи и возврата книг, 
с использованием JWT для аутентификации пользователей (библиотекарей).

## *Технологии*

1. Создаем базу данных в Dockers
   - Для того чтобы проект заработал, нужно в Docker,е создать контейнер 
   **docker run --name patres_container -e POSTGRES_PASSWORD=123 -d postgres**
   - Нужно создать новую базу данных с помощью команды **CREATE DATABASE postgres**
   - 
2.  В проекте были использованы такие зависимости как FastAPI, SQLAlchemy. Остальные указаны в pyproject.toml.

## *Скачиваем программу для визуального отображения таблиц в бд и запускаем проект:*

   - [Dbeaver](https://dbeaver.com/) нажимаем скачать
   и устанавливаем, Docker контейнер должен быть запущен.
   
   - Запускаем программу Dbeaver, в открывшемся окне создаем новое соединение выбираем PostgresSQL,
   жмем далее и не чего не меняем в следующем окне, жмем Готово. С лево появится соединение жмем 
   правой клавишей мышки и выбираем пункт 'Редактировать объект "Соединение" и ставим тот пароль 
   который указан в файле проекта database.py '. Выбираем чуть выше кнопки ок, 'Настройки драйвера' и жмем 
   кнопку по умолчанию и ок. Если автоматически не подключится нажмите изображение похожее на вилку. 
   Открываем соединение с помощью галочки с лево и двигаемся до вкладки таблицы открываем их здесь будут располагаться,
   наши таблицы.

   - Далее переходим в файл database.py и там указаны комментарии куда вставлять модели таблиц для их создания, 
   не забудьте раскомментировать строчку `__table_args__ = {'extend_existing': True}`, она должна стоять в самом низу 
   вашей таблицы на уровне полей. Также нужно раскомментировать блок `try` строчку для удаления таблицы 
   оставить закомментированной, возможно появится ошибка но нужно проверить бд в программе Dbeaver, для того чтобы
   увидеть таблицы нужно отключить бд потом подключить.

   - Так же нужно запустить проект через терминал, набрав команду **uvicorn main:app --reload**,
   в терминале запустится проект и выдаст ссылку для перехода в браузер, нажмите ее и в браузере в адресной строке,
   добавьте **/docs** де вы должны увидеть все эндпоинты проекта.
